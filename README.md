# BDE-Student-Voice
Smart University Residence Complaint Management &amp; Analysis Platform.
## PROJECT IDENTITY :
Project Name: BDE Student Voice

Organization: Bureau Des Étudiants (BDE)

Institution: Cité Universitaire de Tanger, Morocco.

Associated organization: ONOUSC.

Project type: University Residence Complaint Management and AI-Assisted Analysis Platform.

The platform aims to centralize students' complaints, incidents, suggestions, and requests concerning their living and studying conditions in the university residence.

The ultimate objective is to transform individual student feedback into structured, measurable, and actionable information that the BDE can use in discussions with the residence administration.
